# Tony Eletricista - Gestão de Obras

Aplicativo web progressivo, responsivo e instalável para administrar clientes, obras, orçamentos, fotos, vídeos e acompanhamento do cliente.

## Acesso de demonstração

- Administrador: `TONY123`
- Cliente inicial: `CLI123`

## Publicação

Pode ser publicado como site estático no GitHub Pages, Cloudflare Pages, Netlify ou Vercel.

## Importante sobre produção

Esta primeira versão funciona offline e armazena os dados no navegador com `localStorage`. Para uso comercial multiusuário e sincronização real entre celulares, conecte um backend seguro, como Supabase ou Firebase, com autenticação, banco de dados, armazenamento de mídia, regras de acesso e backups.

## Recursos

- Painel gerencial
- Cadastro de clientes e códigos de acesso
- Obras e progresso
- Orçamento com vários itens e cálculo automático
- Fotos e vídeos com texto explicativo
- Portal simplificado do cliente
- Backup em JSON
- PWA instalável e funcionamento offline
- Layout responsivo em azul, amarelo e branco
